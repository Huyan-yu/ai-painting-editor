# AI 绘画编辑器 —— 交付说明

> 选题：与人机协作的 Canvas 绘画编辑器，集成多模态 LLM 评估 + 图像生成参考
>
> 交付日期：2026-09-26

## 一、实现方式 & 时间规划

### 架构

```
frontend/            静态 HTML + Canvas（三层叠加）
  index.html         工具栏 + 画布 + 侧边栏
  app.js             交互逻辑（绘制、评估、生成、撤销）
  style.css
backend/
  mock_ai.py         FastAPI mock：评估 + 生成（无需 API key，默认）
  real_ai.py         真实接入：DeepSeek（评估）+ Agnes（生成），可选
docs/
  交互设计.md         三种交互模式 + 原则
  工作流设计.md       五阶段工作流 + 场景 A-E 的 prompt 特调
```

画布分三层（`user` / `ghost` / `overlay`），互不干扰：
- **user 层**：用户自己画的，AI 永不直接修改
- **ghost 层**：AI 生成参考图（半透明叠加，可拖动/调透明度）
- **overlay 层**：AI 评估标记（断点、视觉重心、不和谐色块）

## 二、人与 AI Agent 互操作交互设计的考量与侧重

### 1. 核心理念：副驾驶，不是代驾
任何 AI 输出（评估、参考图）都**不直接修改用户画面**。AI 只产出的"建议"和"参考"，用户确认后才生效。这是防止"AI 覆盖了我的画"这一最大信任杀手。

### 2. 可逆性
所有 AI 操作（ghost 参考、overlay 标记）可一键撤销。评估建议是只读的，不需要撤销。

### 3. 透明度
- 评估：每条建议标注严重度（info/suggestion/warning），可定位到画布坐标
- 生成：参考图是"灵感起点"，不是"最终答案"，prompt 全程可见

### 4. 触发策略（何时 AI 介入，何时闭嘴）
| 用户信号 | 含义 | AI 动作 |
|---|---|---|
| 停顿 > 10s | 卡住了 | 主动弹 1 条建议（不刷屏） |
| 撤销 ≥ 3 次 | 不确信 | 询问"要看看 AI 评估吗？" |
| 画笔→橡皮切换 | 犹豫 | 静默 |
| 手动点击"AI 看看" | 主动请求 | 完整评估 |

**关键：静默是设计出来的，不是没做。** 不恰当的打扰比没有 AI 更伤信任。

### 5. 渐进信任模型
- 新用户：AI 建议默认折叠
- 接受 5 条后：默认展开（仍不自动应用）
- 接受 15 条后：低风险建议（如色板补全）可自动应用，保留撤销

### 6. 场景细化的 prompt 特调（加分项）
工作流设计文档里，每个绘画阶段有独立的评估维度：
- 草图：构图/视觉重心/留白
- 线稿：断点检测/线宽一致性
- 上色：色相和谐/明度层级/对比度
- 细化：高光完成度/风格统一
- 完成：整体完成度热力图

每个场景的 LLM prompt 要求输出**结构化 JSON**（`issues[]` 含 `position`、`severity`），前端据此在 overlay 层画标记。这是"由工作流驱动 prompt 特调"的具体落地。

## 三、AI 工具与 token 消耗

- **工具**：Codex CLI（本会话）
- **token 估算**：输入 ~60k，输出 ~15k
- **花得最多**：三层画布的交互逻辑（一次生成，无返工）+ 工作流设计文档（场景 prompt 特调）
- mock 后端验证用了一次 curl 调试（JSON 转义小坑，很快解决）

## 四、个人时间花得最多（不算 LLM 直接做的部分）

**交互设计文档**（~40min）：触发策略表和渐进信任模型是手写推敲的，不是 LLM 直接给的——"何时闭嘴"的判断需要人做。这是整个编辑器交互的灵魂，比代码本身花的时间多。

## 五、Mock 与真实接入说明

默认跑 mock（`mock_ai.py`），无需 API key，交互逻辑完全一致。
设 `USE_REAL_AI=1` 后切换 `real_ai.py`：
- 评估：DeepSeek chat API（多模态，传画布截图 + 上下文）
- 生成：Agnes 图像生成 API（按 prompt 出参考图）

## 七、失败案例 / 取舍说明

1. **没做性能优化**：题目明确"不侧重功能实现/性能优化"，基础 canvas 即可。因此没做离屏渲染、WebGL，保持单 canvas 直接绘制。
2. **mock 生成图是纯色占位**：真实 Agnes 接口需要 key，默认不接。前端逻辑已按真实返回（base64 PNG）设计，接上即用。
3. **评估的"断点检测"是 mock 预设值**：真实场景需要前端做线条闭合检测（像素分析）再传给 LLM，本期未做，留作后续。
