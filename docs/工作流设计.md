# 绘画工作流设计与场景细化

## 工作流阶段

```
构思 → 草图 → 线稿 → 上色 → 细化 → 完成
 │      │      │      │      │      │
 │      │      │      │      │      └─ 触发"完成度评估"
 │      │      │      │      └─ 触发"细节一致性检查"
 │      │      │      └─ 触发"色相/配色建议"
 │      │      └─ 触发"线条闭合/连贯性评估"
 │      └─ 触发"构图/透视评估"
 └─ 触发"创意可行性参考生成"
```

每个阶段有对应的评估维度，AI 评估 prompt 随阶段切换。

## 场景细化（LLM 评估 Prompt 特调）

### 场景 A：构图评估（草图阶段）
- 输入：画布截图 + 用户画的元素位置描述
- 评估维度：视觉重心、留白比例、引导线
- Prompt 特调：要求输出 JSON 结构化结果，含 `issues[]` + `suggestions[]` + `severity`
- 用户交互：在画布上叠加"视觉重心"标记，可拖动确认

### 场景 B：线条质量（线稿阶段）
- 输入：线稿层截图 + 闭合状态（前端检测）
- 评估维度：闭合、连贯性、线宽一致性
- Prompt 特调：让 LLM 识别"断点坐标"，前端用红点标出
- 用户交互：断点标记可点击跳转到该区域放大

### 场景 C：配色一致性（上色阶段）
- 输入：当前画面 + 色板（用户选择的 3-5 个主色）
- 评估维度：色相和谐、明度层级、对比度
- Prompt 特调：输出"不和谐色块"的近似位置 + 替代色建议（HEX）
- 用户交互：建议色一键应用（可撤销）

### 场景 D：创意参考生成（构思阶段）
- 输入：用户自然语言描述（"赛博朋克城市，雨夜，霓虹"）
- 生成：参考图（Agnes 图像生成）
- 交互：参考图作为 ghost layer 叠加，用户可调整透明度/位置
- 关键：参考图是"灵感起点"，不是"最终答案"

### 场景 E：完成度评估（完成阶段）
- 输入：最终画面 + 用户声明的"已完成部分"
- 评估维度：各区域完成度、风格统一性
- 输出：完成度热力图（canvas 叠加）
- 用户交互：未达标区域标黄，用户可选择继续细化或接受

## 触发策略（何时 AI 介入）

| 信号 | 含义 | AI 动作 |
|---|---|---|
| 用户停顿 > 10s | 卡住了 | 主动弹出当前阶段的 1 条建议（不刷屏） |
| 用户撤销 ≥ 3 次 | 不确信 | 询问"要看看 AI 评估吗？" |
| 用户点击画笔后又切橡皮 | 犹豫 | 静默，不打扰 |
| 用户手动点击"AI 看看" | 主动请求 | 完整评估当前阶段 |
| 用户切换工具 > 2min 没用 | 闲置 | 静默，不打扰 |

## 信任度渐进模型

- 新用户：AI 建议默认折叠，需手动展开
- 连续接受 5 条建议后：AI 建议默认展开（仍不自动应用）
- 连续接受 15 条后：部分低风险建议（如色板补全）可自动应用，但保留撤销

## 数据流（前端 → 后端）

```
评估请求: { stage, canvas_base64, context: { colors, elements, user_note }, timestamp }
生成请求: { prompt, reference_canvas_base64, size }
响应:     { issues[], suggestions[], reference_image_url, confidence }
```

Mock 模式下后端返回预制的合理响应，前端交互逻辑完全一致。
